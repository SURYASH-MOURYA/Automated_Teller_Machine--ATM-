# Automated_Teller_Machine-ATM-

Functional ATM  Java project

This project generates an automated teller machine (ATM) that stores the user's bank account, acount number, and password. With this ATM, users will be able to:  Make deposits Withdraw money View their account balance


To run the project:

Clone the ATM-Machine repo to your local machine
Make sure the ATM.java, Account.java, and OptionMenu.java files are stored in a single folder
Use Java IDE (e.g. VS  Code, Eclipse, IntelliJ) to view these files
You can also use commmand prompt (Windows) or terminal (Mac/Linux) and cd to the project directory to view them
In command prompt or terminal run command : javac ATM.java
After completion your folder will contain 3 .class files
In command prompt/terminal run command: java ATM
